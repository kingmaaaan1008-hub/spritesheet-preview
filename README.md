# スプライトシート プレビュー

RPG 用スプライトシート（[SpriteSheetCreater](https://github.com/) で生成）の公開プレビュー。

- 公開ページ: https://kingmaaaan1008-hub.github.io/spritesheet-preview/
- `<キャラ名>.png` … スプライトシート本体
- `<キャラ名>.json` … 各アニメーションのフレーム矩形（Unity / Godot / Phaser 用）

このリポジトリは `node scripts/publish_pages.mjs` で自動生成・同期されます（手で編集しないこと）。
